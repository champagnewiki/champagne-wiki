## AI Agents & Multi-Agent Frameworks

</AISectionHeader>

Agent frameworks give a language model the ability to plan, call tools, and act autonomously instead of just answering a single prompt. The space splits into single-agent frameworks built for one autonomous actor, and multi-agent orchestration frameworks designed to coordinate several agents working together on the same task.

<ToolDeck columns={2}>
  <ToolCard title="AutoGPT" href="https://github.com/Significant-Gravitas/AutoGPT" icon={<Bot />} badge="183K Stars" badgeStyle="indigo">
    The original autonomous agent framework that sparked the agent movement, with modular architecture and forge-based agent building.
  </ToolCard>
  <ToolCard title="LangChain / LangGraph" href="https://langchain.com" icon={<Bot />} badge="Foundational" badgeStyle="indigo">
    The foundational library for agents, chains, and memory — LangGraph adds stateful, controllable agent orchestration on top.
  </ToolCard>
  <ToolCard title="Google ADK" href="https://google.github.io/adk-docs" icon={<Bot />} badge="Apache 2.0" badgeStyle="emerald">
    Code-first Python toolkit for sophisticated multi-agent orchestration with built-in evaluation, model-agnostic but tightly integrated with Google's ecosystem.
  </ToolCard>
  <ToolCard title="Pydantic AI" href="https://ai.pydantic.dev" icon={<Bot />} badge="MIT" badgeStyle="emerald">
    Type-safe agent framework from the creators of Pydantic, with broad model provider support, built-in observability, and MCP/A2A protocol support.
  </ToolCard>
</ToolDeck>

### Agent Protocols & Context Standards

</AISectionHeader>

As agent ecosystems mature, standardized protocols are emerging so agents built on different frameworks can still talk to each other, share memory, and expose tools safely.

<PillDeck>
  <AIPill title="Model Context Protocol (MCP)" href="https://modelcontextprotocol.io" type="official" />
  <AIPill title="Agent File Format (.af)" href="https://github.com/letta-ai/agent-file" type="open" />
  <AIPill title="Agent Skills spec" href="https://github.com/anthropics/skills" type="open" />
  <AIPill title="FastMCP" href="https://github.com/jlowin/fastmcp" type="open" />
</PillDeck>

<GuideBox title="Memory & context infrastructure" tone="success">
  Long-running agents need persistent memory beyond a single context window. Tools like <strong>Letta</strong>, dedicated memory-engine APIs, and local-first memory lifecycles (e.g. Ring Memory) let agents store, retrieve, and reuse context across sessions without re-processing everything from scratch each run.
</GuideBox>

## Autonomous Coding Agents

</AISectionHeader>

These agents operate directly inside your terminal or repository — reading code, writing patches, running tests, and iterating without constant hand-holding. Most fall into either an IDE-integrated assistant or a fully terminal-native harness that manages its own subagents and memory.

<ToolDeck columns={2}>
  <ToolCard title="OpenHands" href="https://github.com/All-Hands-AI/OpenHands" icon={<Terminal />} badge="Full Agent" badgeStyle="indigo">
    Full-featured open-source AI software engineer, formerly OpenDevin, built for end-to-end autonomous development tasks.
  </ToolCard>
  <ToolCard title="Gemini CLI" href="https://github.com/google-gemini/gemini-cli" icon={<Terminal />} badge="Apache 2.0" badgeStyle="emerald">
    Open-source agent bringing Gemini's capabilities directly into your terminal, with code generation and shell execution.
  </ToolCard>
  <ToolCard title="Mini-SWE-agent" href="https://github.com/SWE-agent/mini-swe-agent" icon={<Terminal />} badge="Lightweight" badgeStyle="amber">
    Lightweight coding agent purpose-built for repository and issue-fixing workflows and agentic SWE experiments.
  </ToolCard>
  <ToolCard title="Continue" href="https://continue.dev" icon={<Terminal />} badge="IDE-Native" badgeStyle="indigo">
    Open-source AI code assistant that connects any model into custom autocomplete and chat inside your IDE.
  </ToolCard>
</ToolDeck>

<AISectionHeader icon={<Wrench />} accent="pink">

### Personal AI Assistants

</AISectionHeader>

Distinct from coding agents, this class of tool lives in your everyday messaging apps — Telegram, WhatsApp, Discord, Slack — and handles real-world tasks like email, scheduling, and browsing on your behalf rather than writing code.

<ToolDeck columns={2}>
  <ToolCard title="OpenClaw" href="https://openclaw.ai" icon={<Wrench />} badge="Viral / OSS" badgeStyle="indigo">
    Open agent platform that runs on your machine and works from the chat apps you already use — WhatsApp, Telegram, Discord, Slack, Teams. Broad ecosystem with a large community skill marketplace (Clawhub), though cross-session memory needs manual setup.
  </ToolCard>
  <ToolCard title="Hermes Agent" href="https://hermes-agent.nousresearch.com" icon={<Wrench />} badge="Self-Improving" badgeStyle="emerald">
    MIT-licensed agent from Nous Research with a built-in closed learning loop — it writes reusable skills from completed tasks and builds persistent memory automatically. Supports 200+ models and can migrate an existing OpenClaw setup directly.
  </ToolCard>
</ToolDeck>

<PillDeck>
  <AIPill title="Khoj" href="https://khoj.dev" type="open" />
  <AIPill title="Leon" href="https://getleon.ai" type="open" />
  <AIPill title="Home Assistant Voice" href="https://home-assistant.io" type="open" />
</PillDeck>

<GuideBox title="OpenClaw vs. Hermes Agent" tone="neutral">
  These two are often run together rather than as competitors: OpenClaw contributes ecosystem breadth and multi-channel orchestration, while Hermes Agent contributes the persistent memory and self-improving skill layer that OpenClaw lacks out of the box. A common setup runs Hermes as a high-level planner on top of OpenClaw's tools.
</GuideBox>
