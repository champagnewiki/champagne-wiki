## File Transfer & P2P Sharing

</StorageSectionHeader>

Instant peer-to-peer sending and local device synchronization for moving files quickly across platforms without permanent cloud storage.

<InfoDeck>
  <InfoCard title="LocalSend" href="https://localsend.org/" icon={<Send />} tag="Featured ⭐" tagStyle="rose">
    Free, open-source local file sharing across Windows, macOS, Linux, Android, and iOS. Check out the <a href="https://web.localsend.org/" target="_blank">Web Version</a>, <a href="https://discord.com/invite/GSRWmQNP87" target="_blank">Discord</a>, and <a href="https://github.com/localsend/localsend" target="_blank">GitHub</a>.
  </InfoCard>
  <InfoCard title="Blip" href="https://blip.net/" tag="Featured ⭐" tagStyle="rose" icon={<Share2 />}>
    Hybrid P2P transfer network supporting Windows, macOS, Android, and iOS. <br/>**Tip:** Turn "Searchable by Name" off in settings for enhanced privacy.
  </InfoCard>
  <InfoCard title="PairDrop" href="https://pairdrop.net/" tag="Web ⭐" tagStyle="amber" icon={<Globe />}>
    An open-source, browser-based peer-to-peer file sharing tool inspired by AirDrop. Alternative mirror: <a href="https://node-snapdrop.onrender.com/" target="_blank">Snapdrop</a>.
  </InfoCard>
  <InfoCard title="JustBeamIt" href="https://justbeamit.com/" tag="Web ⭐" tagStyle="amber" icon={<Share2 />}>
    Instant browser-based direct file transfer where files are streamed straight between peers without intermediate cloud storage.
  </InfoCard>
  <InfoCard title="Wormhole" href="https://wormhole.app/" tag="Encrypted" tagStyle="violet" icon={<Share2 />}>
    End-to-end encrypted file sharing with automatic 24-hour expiration. Join their <a href="https://discord.com/invite/de6FscsK5Z" target="_blank">Discord</a> or view <a href="https://github.com/webtorrent/wormhole-crypto" target="_blank">GitHub</a>.
  </InfoCard>
  <InfoCard title="OnionShare" href="https://onionshare.org/" tag="Tor Network" tagStyle="sky" icon={<Globe />}>
    Open-source tool to securely and anonymously share files hosted locally over the Tor network. Available on all desktop & mobile platforms.
  </InfoCard>
  <InfoCard title="Photon" href="https://photondev.netlify.app/" tag="Local P2P" tagStyle="neutral" icon={<Send />}>
    Local file transfer utility for Windows, macOS, Linux, and Android. Source code available on <a href="https://github.com/abhi16180/photon" target="_blank">GitHub</a>.
  </InfoCard>
  <InfoCard title="KDE Connect" href="https://kdeconnect.kde.org/" tag="Ecosystem" tagStyle="neutral" icon={<FolderSync />}>
    Links your phone and computer seamlessly across platforms for shared clipboard, file transfers, and notifications.
  </InfoCard>
  <InfoCard title="LANDrop" href="https://landrop.app/" tag="Cross-Platform" tagStyle="neutral" icon={<Globe />}>
    Drop files to any device on your LAN securely and without internet. Check out their <a href="https://discord.com/invite/5adm6sPugT" target="_blank">Discord</a>.
  </InfoCard>
  <InfoCard title="Magic Wormhole" href="https://github.com/magic-wormhole/magic-wormhole" tag="CLI / GUI" tagStyle="neutral" icon={<Cpu />}>
    Get things from one computer to another safely via code words across Windows, macOS, Linux, and Android.
  </InfoCard>
</InfoDeck>

## File Hosts & Retention Storage

</StorageSectionHeader>

Public file hosts categorized by storage limits and retention periods. Remember that files are frequently purged after inactivity.

<InfoDeck>
  <InfoCard title="Gofile" href="https://gofile.io/" tag="Featured ⭐" tagStyle="rose" icon={<Server />}>
    100GB monthly limit with unlimited file size. Files are retained for 10 days after the last download. Automated manager script available on <a href="https://greasyfork.org/en/scripts/515250" target="_blank">GreasyFork</a>.
  </InfoCard>
  <InfoCard title="Pixeldrain" href="https://pixeldrain.com/" tag="Featured ⭐" tagStyle="rose" icon={<Server />}>
    10GB max file size, 60 days retention after last download. Features <a href="https://docs.pixeldrain.com/questions_and_answers/#alternative-domain-names" target="_blank">alternative mirrors</a> and a <a href="https://pixeldrain.com/speedtest" target="_blank">speedtest tool</a>.
  </InfoCard>
  <InfoCard title="VikingFile" href="https://vikingfile.com/" tag="Featured ⭐" tagStyle="rose" icon={<Server />}>
    Unlimited storage tier with 15 days retention after the last download. Join the <a href="https://discord.gg/EPEFC6KkpF" target="_blank">Discord</a> community.
  </InfoCard>
  <InfoCard title="0807" href="https://0807.st/" tag="Featured ⭐" tagStyle="rose" icon={<Server />}>
    10GB storage limit, 90 days retention after the last download. Open-source code available on <a href="https://codeberg.org/Sauul/0807" target="_blank">Codeberg</a>.
  </InfoCard>
  <InfoCard title="ZeroFS" href="https://zerofs.link/" tag="Featured ⭐" tagStyle="rose" icon={<Server />}>
    Unlimited file hosting with 15 days retention after last download. CLI tool available on <a href="https://github.com/kirmola/zerofs-cli" target="_blank">GitHub</a>.
  </InfoCard>
  <InfoCard title="Catbox" href="https://catbox.moe/" tag="Featured ⭐" tagStyle="amber" icon={<Server />}>
    200MB limit. Permanent retention with an account (2 years for inactive anonymous files). Includes official <a href="https://fatbox.moe/" target="_blank">Fatbox Proxy</a>.
  </InfoCard>
  <InfoCard title="Pillowcase" href="https://pillows.su/" tag="Audio Host" tagStyle="violet" icon={<Server />}>
    Dedicated audio file host supporting up to 500MB with permanent retention for uploaded audio files.
  </InfoCard>
  <InfoCard title="MediaFire" href="https://www.mediafire.com/" tag="4GB Limit" tagStyle="neutral" icon={<HardDrive />}>
    Classic long-term file host offering up to 4GB file sizes with permanent storage retention tiers.
  </InfoCard>
</InfoDeck>
