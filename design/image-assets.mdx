</GfxSectionHeader>

## Fonts

</GfxSectionHeader>

Good typography defines a design. Always check the commercial license status before embedding a free font into a client project. When you know exactly what typeface you want, use the search syntax below to find the raw `.ttf` or `.otf` files.

<DorkBlock>
  <span className="text-zinc-500"># HOW TO DORK ANY FONT YOU WANT</span><br/>
  <span className="text-emerald-400">1. Find the name of the exact typeface (e.g. Proxima Nova)</span><br/>
  <span className="text-emerald-400">2. Run these exact search strings in Google:</span><br/><br/>
  <span className="text-indigo-300">proxima nova.ttf</span><br/>
  <span className="text-indigo-300">site:vk.com proxima nova.ttf</span><br/>
  <span className="text-indigo-300">site:github.com proxima nova.ttf</span><br/><br/>
  <span className="text-emerald-400">3. Alternatively, search directly inside GitHub:</span><br/>
  <span className="text-indigo-300">extension:ttf extension:otf filename:proxima nova</span>
</DorkBlock>
