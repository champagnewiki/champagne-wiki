## Dedicated IPTV Players

</LiveTVSectionHeading>

If you want to use the raw M3U8 playlists found in the indexes above (like `i.mjh.nz` or the `Free-TV Repo`), you need dedicated client software to play them. These apps process the raw links into a beautiful, navigable TV interface and pull in Electronic Program Guides (EPG).

<SiteDeck columns={2}>
  <SiteCard title="TiviMate" href="https://tivimate.com/" badge="software" icon={<Tv />} starred>
Considered the absolute gold standard for Android TV and Firestick setups. Features a flawless, native TV guide (EPG) interface, recording capabilities, and multi-screen viewing.
  </SiteCard>
  <SiteCard title="SFVIP Player" href="https://www.lativ.me/sfvip-player" badge="software" icon={<MonitorPlay />} starred>
An incredibly powerful, lightweight IPTV player explicitly built for Windows. Supports MAC portals, Xtream Codes, and standard M3U lists flawlessly.
  </SiteCard>
  <SiteCard title="IPTV Smarters Pro" href="https://www.iptvsmarters.com/" badge="software" icon={<MonitorSmartphone />}>
A highly versatile, cross-platform player (iOS/Android/Web) supporting both raw M3U URLs and Xtream Codes API logins for organized VOD and Live TV tabs.
  </SiteCard>
  <SiteCard title="Sparkle TV" href="https://play.google.com/store/apps/details?id=se.hedekonsult.sparkle" badge="software" icon={<Tv />}>
A very strong alternative to TiviMate for Android TV users, offering excellent Timeshift (catch-up) support and a robust DVR interface.
  </SiteCard>
  <SiteCard title="Televizo" href="https://televizo.net/" badge="software" icon={<MonitorSmartphone />}>
A lightweight, highly customizable player for Android mobile devices featuring robust EPG syncing and a clean, ad-free interface.
  </SiteCard>
  <SiteCard title="IINA / VLC Media Player" href="https://iina.io/" badge="software" icon={<MonitorPlay />}>
The ultimate free, open-source fallbacks for Mac (IINA) and PC (VLC). Simply go to <i>File - Open Network Stream</i> and paste your M3U8 link to start watching instantly.
  </SiteCard>
</SiteDeck>

<WarnBox>
Region-specific players sometimes geoblock based on IP. A VPN set to the relevant country will usually resolve access issues if a stream refuses to load.
</WarnBox>
