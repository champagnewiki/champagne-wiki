</GamingSectionHeading>

<ZoneIntro accent="violet">
  Steam, Epic, and GOG all lock certain features (DLC access, offline multiplayer, achievements) behind their own servers. This section covers the tools that unlock, organize, and manage those libraries, from DRM bypasses to cross-platform launchers.

### Steam & Epic Tool Index

</GamingSectionHeading>

<InfoDeck>
  <InfoCard title="Koalageddon" href="https://github.com/acidicoala/Koalageddon2" icon={<Layers />} tag="DLC unlocker" tagStyle="violet">
    Unlocks purchasable DLC across Steam, Epic, Origin, EA, and Uplay in one tool, works by intercepting each platform's own ownership check.

### Offline Activation Tools

</GamingSectionHeading>

<ZoneIntro accent="rose">
  Offline activation services provide access to shared legitimate game licenses. These tools ensure you download the exact, unmodified version of game files required to match those licenses for activation.
</ZoneIntro>

<InfoDeck>
  <InfoCard title="Cirno-DL" href="https://discord.gg/anti-denuvo-sanctuary" icon={<HardDrive />} tag="Windows" tagStyle="rose">
    The official downloader for the Anti-Denuvo Sanctuary offline activation service. It ensures you download pristine, unmodified game files required to match shared legit licenses.
  </InfoCard>
  <InfoCard title="SLSsteam" href="https://github.com/AceSLS/SLSsteam/wiki/Installation" icon={<Cpu />} tag="Linux" tagStyle="rose">
    An offline activation client specifically for Linux users, enabling the verification and use of shared legit game licenses on Linux-based systems.
  </InfoCard>

## Performance & Input

</GamingSectionHeading>

<ZoneIntro accent="amber">

</ZoneIntro>

<GamingSectionHeading icon={<Cpu />} accent="amber">

</GamingSectionHeading>

<InfoDeck>
  <InfoCard title="Special K" href="https://www.special-k.info/" icon={<Cpu />} tag="Universal injector" tagStyle="amber">

## Homebrew & Consoles

</GamingSectionHeading>

<ZoneIntro accent="violet">
  Console modding is highly firmware-version dependent, a guide written for one system update can permanently soft-brick a device on another. Always confirm your exact firmware version against the guide's stated compatibility before doing anything irreversible.
</ZoneIntro>

<GuideBox title="Before You Start" tone="danger">
  Check your console's exact firmware/OFW version first. Many exploits are patched in later updates, and some downgrade paths carry a real brick risk. When in doubt, ask in the relevant Discord before flashing anything.
</GuideBox>
